# Dr Ismail Garba — personal research website

A responsive static website starter built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a modern browser. An internet connection is used for Google Fonts and the remote Unsplash photo backgrounds.

## Before publishing
1. Replace the portrait placeholder with an approved professional photograph.
2. Replace `YOUR_EMAIL@example.com` with the professional email address you want to publish.
3. Add verified ORCID, Google Scholar, LinkedIn and GitHub links if desired.
4. Verify publication authorship, journal details, DOI and add the remaining publications.
5. Review project descriptions and confirm which project names and outputs can be made public.
6. Replace remote image URLs with licensed/owned images if preferred.

## Deploy
This is a static site and can be hosted on GitHub Pages, Netlify, Vercel or a standard web host. No build step is required.
